# Menú Interactivo KATSURI

Catálogo web dinámico para el emprendimiento de postres "KATSURI". Permite visualizar los productos disponibles y genera enlaces de pedido automatizados directos a WhatsApp.

## Características Principales (En desarrollo)
*   **Interfaz de usuario atractiva:** Diseño moderno y responsivo para mostrar el menú de galletas y donas.
*   **Gestión de inventario visual:** (Próximamente) Indicadores de stock en las tarjetas de productos.
*   **Pedidos vía WhatsApp:** Botones de acción integrados con la API de WhatsApp para facilitar la compra directa.

## Stack Tecnológico
*   **Estructura:** HTML5 Semántico
*   **Diseño:** CSS3 
*   **Lógica e Interacción:** JavaScript (Vanilla JS)

## Estructura del Proyecto
*   `/css`: Archivos de estilo.
*   `/js`: Lógica de interacción y conexión a WhatsApp.
*   `/assets/img`: Galería de productos KATSURI.
